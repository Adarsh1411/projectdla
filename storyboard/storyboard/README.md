### This directory would contain images of the [storyboard document](https://github.com/virtual-labs/ph3-exp-dev-process/blob/main/storyboard/README.org).
A storyboard is a graphic organizer in the form of illustrations or images displayed in sequence. It is used to visualize the different stages of an interactive media sequence.

In this experiment, the storyboard represents the working process of the Diffusion-Limited Aggregation (DLA) simulation. It shows how the user moves from the introduction to particle aggregation, fractal analysis, and the final result.
