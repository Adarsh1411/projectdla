# Procedure

1. Open the DLA simulation website in a web browser.
2. Initialize the simulation with a seed particle at the center.
3. Generate particles that move randomly around the seed.
4. Allow each particle to stick to the existing cluster when it comes into contact with it.
5. Repeat the process to generate a branching fractal pattern.
6. Observe the growth and structure of the cluster.
7. Apply the box-counting method using boxes of different sizes.
8. Count the boxes that contain part of the cluster.
9. Estimate the fractal dimension using the logarithmic relationship.
10. Record and analyze the results.
