How it works

01

Release

A particle starts at a random point near the edge of the growth region.

02

Random walk

It moves one grid cell at a time in a randomly chosen direction.

03

Stick

If it touches the existing cluster, it joins the aggregate.

04

Estimate

Box counting estimates dimension from how occupied boxes scale with box size.

D ≈ slope of log N(ε) / log(1/ε)
